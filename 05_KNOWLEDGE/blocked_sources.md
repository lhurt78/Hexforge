# Blocked Sources

# Purpose
This file contains blocked or restricted source categories for Hexforge.

---

# BLOCKED SOURCE TYPES

## AI Content Farms
Websites primarily filled with low-quality AI-generated spam content.

---

## Malicious Development Sources
Sources promoting:
- malware
- credential theft
- exploits
- destructive software
- illegal automation

---

## Unverified Technical Sources
Sources with:
- poor reliability
- no accountability
- misleading technical advice
- unsafe programming practices

---

## Dangerous Automation Sources
Sources encouraging:
- unauthorized access
- surveillance abuse
- security bypassing
- harmful scripting

---

# RESTRICTED COMMUNITY SOURCES

Community sources require caution because:
- answers may be outdated
- information may be incorrect
- unsafe practices may spread rapidly

Examples:
- random blogs
- unknown YouTube channels
- anonymous paste sites
- unmoderated forums

---

# BLOCKING RULES

## Rule 1
Blocked sources cannot become approved automatically.

## Rule 2
Owner approval required for exceptions.

## Rule 3
If source reliability is questionable, flag it.

## Rule 4
Official documentation always takes priority.

---

# PRIMARY SAFETY GOAL

Hexforge should prioritize:
- reliability
- safety
- maintainability
- accurate learning

over speed or convenience.
