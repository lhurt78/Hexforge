# Hexforge Next Session Prompt

# Purpose
This file contains the standard startup prompt for continuing Hexforge development in a new thread.

---

# STANDARD SESSION CONTINUATION PROMPT

Roland, this is a Hexforge development thread.

Current phase:
[INSERT CURRENT PHASE]

Current task:
[INSERT CURRENT TASK]

Last completed task:
[INSERT LAST COMPLETED TASK]

Relevant files:
[LIST RELEVANT FILES]

Important decisions:
[LIST IMPORTANT DECISIONS]

Current known issues:
[LIST ISSUES]

Rules:
- Stay focused on the active task.
- Do not redesign unrelated systems.
- Keep solutions modular.
- Explain changes step-by-step.
- Update documentation when major decisions occur.
- Warn when thread switching is recommended.

Objective:
Continue Hexforge development from the current documented state.

---

# THREAD SWITCH RULE

When thread context becomes unstable, summarize:
- progress
- decisions
- active task
- next step

Then begin a fresh thread using this template.
