# THREAD MANAGEMENT POLICY

When a thread becomes:
- too large
- unfocused
- repetitive
- unstable

development pauses and moves to a fresh thread.

Before switching threads:
1. update documentation
2. summarize current progress
3. define the next task clearly

This prevents context degradation.
