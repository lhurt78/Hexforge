# Hexforge Research Architecture

# Purpose
This document defines how Hexforge retrieves, validates, stores, and uses external information.

---

# PRIMARY RESEARCH PHILOSOPHY

Hexforge does not freely browse the internet.

Research must remain:
- controlled
- documented
- source-approved
- verifiable
- relevant to user goals

The goal is reliable information retrieval rather than unrestricted exploration.

---

# RESEARCH PIPELINE

All research should follow this sequence:

1. User request
2. Query generation
3. Source approval check
4. Information retrieval
5. Source validation
6. Summary generation
7. Research logging
8. Optional knowledge storage
